1. Read `docs/agents/tasks/BOARD.md` for the next free ID and `docs/agents/tasks/_TEMPLATE.md`.
2. Find the files in scope with Grep/Glob or the `scout` subagent. Do not read whole modules.

4. Append the BOARD row(s). Show the user the card IDs and owners only.
