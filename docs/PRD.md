# Founder OS — Phase 0 PRD

Founder OS privately connects problems, ideas, research, projects, operational state, distribution and business. Phase 0 establishes the secure technical foundation only; it does not implement Idea OS, Project OS, research workflows, portfolio publishing or integrations.

Core invariants: private by default, human decisions over AI recommendations, Idea and Project remain distinct, lifecycle and operational status remain independent, and GitHub remains the source of truth for issues and technical work.
