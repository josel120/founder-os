## Goal
Server-side Decision Log behavior. The owner records human decisions (title, decision, reason), optionally linked to one of their ideas. No AI-generated decisions (PRD: human decisions over AI recommendations).

## Acceptance criteria
- [ ] `src/modules/decisions/schemas/decision.schema.ts`: Zod create schema (title ≤160, decision ≤2000, reason ≤2000, all required, trimmed; optional `ideaId` uuid).
- [ ] `createDecision(formData)` returns `{ ok: true } | { ok: false; error }` for unauthorized / invalid / no db / insert failure / success. Inserts `ownerId` from the session and `visibility: "PRIVATE"`.
- [ ] If `ideaId` is given, the idea must match id + owner + PRIVATE, otherwise an explicit error and no insert (pattern: `createIdeaFromProblem`).
- [ ] `listPrivateDecisions()` and `listDecisionsForIdea(ideaId)` are scoped to owner + PRIVATE, newest first.
- [ ] Tests assert the owner/PRIVATE SQL predicates and the cross-owner idea rejection (pattern: `tests/problem-to-idea.test.ts`).
- [ ] `pnpm typecheck`, lint on changed files and unit tests pass (exit codes in handoff)
