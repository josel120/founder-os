# T-068: Publication domain: publish actions and allowlisted public queries

- Status: todo
- Owner: claude
- Size: M
- Depends on: T-066

## Goal
The owner can publish and unpublish a project server-side, and public code can read only the allowlisted fields of published projects.

## Acceptance criteria
- [ ] `src/modules/portfolio`: `publishProject`/`unpublishProject` server actions (Zod, `requireAuth`, project matched by `id + owner_id`, `INSERT … ON CONFLICT DO UPDATE … RETURNING` / `DELETE … RETURNING`, explicit result, `reportError` on failure, path revalidation).
- [ ] `getPrivatePublication(projectId)` for the owner, and public queries `listPublicProjects()` (PUBLIC only, newest first) and `getPublishedProject(slug)` (PUBLIC or UNLISTED) that select only the ADR-018 allowlist and join on `project_id` and `owner_id`.
- [ ] Tests: another owner cannot publish or unpublish; anonymous calls are rejected; public queries never return private projects, other columns, or a publication whose owner differs from the project's; unpublish removes the row.
- [ ] `reviewer` and `privacy-auditor` pass; `pnpm lint`, `pnpm typecheck` and `pnpm test` pass (exit codes in handoff).
