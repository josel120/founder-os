# T-079: CSV parser, column mapping and duplicate keys

- Status: todo
- Owner: claude
- Size: M
- Depends on: T-078

## Goal
Pure, well-tested code turns CSV text and a mapping into validated transaction rows with import keys.

## Acceptance criteria
- [ ] RFC 4180 parser (quotes, doubled quotes, comma/semicolon, CRLF/LF, BOM), limits (1 MB, 5,000 rows) with clear errors.
- [ ] Mapping schema (Zod) and row conversion: date formats, decimal separator, sign → type, currency column or fixed, category from description (trimmed, ≤ 200), exact decimals as strings; per-row errors with row numbers, never throwing.
- [ ] `importKey` per ADR-020 (external ID, else SHA-256 of normalized fields + occurrence number).
- [ ] Thorough unit tests (edge cases, locales, duplicates within a file); `reviewer`; `pnpm lint`, `pnpm typecheck`, `pnpm test` pass.

- `tests/finance-import-*.test.ts`
