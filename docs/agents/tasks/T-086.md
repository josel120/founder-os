# T-086: Anthropic client, prompt builder and output schema

- Status: todo
- Owner: claude
- Size: M
- Depends on: T-084

## Goal
A server-only service that builds the allowlisted prompt, calls the Messages API with forced tool use and returns a validated result or an error code.

## Acceptance criteria
- [ ] Env: `ANTHROPIC_API_KEY`, `AI_MODEL` (default `claude-sonnet-5`), test-only `AI_API_URL` refused under strict env; invalid optional values turn the feature off
- [ ] Prompt uses only the ADR-021 allowlist, caps input at 40,000 characters (oldest evidence dropped first) and carries `prompt_version`
- [ ] Output parsed with Zod; timeouts, 401/403, 429, 5xx and bad output map to error codes; key and bodies never logged
- [ ] `AIService` reduced to `assessIdea` and `summarizeResearch`
- [ ] Tests added or updated for changed behavior
- [ ] `pnpm typecheck`, lint on changed files and unit tests pass (exit codes in handoff)
