# T-069: Owner publish panel with a preview of what becomes public

- Status: todo
- Owner: claude
- Size: M
- Depends on: T-068

## Goal
On a project's page the owner writes a public summary, picks Public or Unlisted, sees exactly what will be public, and publishes or unpublishes.

## Acceptance criteria
- [ ] Panel on `/private/projects/[id]`: current state (Private / Unlisted / Public with the public link), summary field with a counter, visibility choice, a preview built from the same allowlist as the public page, publish/update and unpublish with a confirmation step, accessible errors.
- [ ] The preview never shows fields outside the allowlist; a test proves the private description and next action are absent from it.
- [ ] `reviewer` passes; `pnpm lint`, `pnpm typecheck` and `pnpm test` pass (exit codes in handoff).
