# T-004: Problem → Idea conversion

- Status: todo
- Owner: claude
- Size: M
- Depends on: T-003

## Goal
From a Problem the owner can create an Idea linked via `idea.problem_id`. Both records must belong to the same owner.

## Acceptance criteria
- [ ] Server action checks that the problem is `id + owner_id + PRIVATE` before inserting the idea with `problem_id`.
- [ ] A problem ID from another owner, or an unknown ID, returns an explicit error and inserts nothing.
- [ ] The idea detail page shows the linked problem title (owner-scoped query).
- [ ] Tests cover the cross-owner rejection and the success case.
- [ ] `pnpm typecheck`, lint on changed files and unit tests pass (exit codes in handoff)
