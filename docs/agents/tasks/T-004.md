# T-004: Problem → Idea conversion

- Status: done
- Owner: claude
- Size: M
- Depends on: T-003

## Goal
From a Problem the owner can create an Idea linked via `idea.problem_id`. Both records must belong to the same owner.

## Acceptance criteria
- [x] Server action checks that the problem is `id + owner_id + PRIVATE` before inserting the idea with `problem_id`.
- [x] A problem ID from another owner, or an unknown ID, returns an explicit error and inserts nothing.
- [x] The idea detail page shows the linked problem title (owner-scoped query).
- [x] Tests cover the cross-owner rejection and the success case.
- [x] `pnpm typecheck`, lint on changed files and unit tests pass (exit codes in handoff)
