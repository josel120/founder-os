# T-076: Project GitHub panel, refresh, daily cron and stale-repo attention

- Status: todo
- Owner: claude
- Size: M
- Depends on: T-075

## Goal
The owner sees each project's repository activity, can refresh it, it refreshes daily, and the home lists stale repositories.

## Acceptance criteria
- [ ] Project page panel: repo link, last push, open issues and PRs, latest release, synced-at, error message per code, a Refresh button (owner-scoped action); a clear note when `GITHUB_TOKEN` is not configured.
- [ ] `/api/cron/github` (GET, `Authorization: Bearer CRON_SECRET`, constant-time compare, 401 otherwise) runs `syncAllLinkedProjects`; `vercel.json` cron at 06:00 UTC.
- [ ] `/private` home: projects with `last_push_at` ≥ 30 days ago.
- [ ] Tests; `reviewer` + `privacy-auditor`; `pnpm lint`, `pnpm typecheck`, `pnpm test` pass.

## Files in scope
- `src/modules/github/components/**`, `src/app/private/projects/[id]/page.tsx`, `src/app/api/cron/github/route.ts`, `vercel.json`, `src/modules/cockpit/**`, `tests/**`
