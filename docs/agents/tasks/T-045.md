# T-045: Add a nonce-based script-src Content Security Policy

- Status: todo
- Owner: claude
- Size: M
- Depends on: T-043

## Goal
Block injected scripts. T-043 set `frame-ancestors`, `object-src`, `base-uri` and `form-action`, but no `script-src`: Next.js inline scripts need a per-request nonce.

## Acceptance criteria
- [ ] Middleware generates a nonce per request and sets `Content-Security-Policy` with `script-src 'self' 'nonce-…' 'strict-dynamic'` (plus `'unsafe-eval'` only in dev)
- [ ] The nonce reaches Next.js via the request header, so framework scripts carry it; no console CSP violations on any page
- [ ] Middleware keeps ADR-014 behavior: server action POSTs pass through; the `/private` cookie redirect is unchanged
- [ ] E2E asserts the header on a public and a private page; full E2E passes

## Files in scope
- `src/middleware.ts`, `next.config.ts`, `tests/middleware.test.ts`, `tests/e2e/auth-ui.spec.ts`, `docs/DECISIONS.md`

## Context (read only these)

## Out of scope
- Third-party scripts (there are none)
