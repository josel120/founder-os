# T-045: Add a nonce-based script-src Content Security Policy

- Status: review
- Owner: claude
- Size: M
- Depends on: T-043

## Goal
Block injected scripts. T-043 set `frame-ancestors`, `object-src`, `base-uri` and `form-action`, but no `script-src`: Next.js inline scripts need a per-request nonce.

## Acceptance criteria
- [x] Middleware generates a nonce per request and sets `Content-Security-Policy` with `script-src 'self' 'nonce-…' 'strict-dynamic'` (plus `'unsafe-eval'` only in dev)
- [x] The nonce reaches Next.js via the request header, so framework scripts carry it; no console CSP violations on any page
- [x] Middleware keeps ADR-014 behavior: server action POSTs pass through; the `/private` cookie redirect is unchanged
- [x] E2E asserts the header on a public and a private page; full E2E passes
