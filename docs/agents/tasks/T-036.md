# T-036: Build the private Research UI

- Status: todo
- Owner: codex
- Size: M
- Depends on: T-034, T-035

## Goal
The owner can capture, edit and review evidence from a Research page and from an Idea's detail page.

## Acceptance criteria
- [ ] `/private/research`: evidence list with kind/signal filters, plus a capture form whose parent select only offers the owner's problems and ideas.
- [ ] The Idea detail page shows that idea's evidence (supports/contradicts counts) and a capture form pre-bound to the idea.
- [ ] Inline edit of evidence content with error feedback from the explicit results.
- [ ] Source links use `rel="noopener noreferrer nofollow"` and `target="_blank"`. The page is dynamic and behind auth. A Research nav link is added.
- [ ] Component tests (pattern: `tests/finance-forms.test.tsx`).
- [ ] `pnpm typecheck`, lint on changed files and unit tests pass (exit codes in handoff)
