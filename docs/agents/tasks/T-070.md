# T-070: Public portfolio and project pages

- Status: todo
- Owner: claude
- Size: M
- Depends on: T-068

## Goal
Visitors see the owner's public projects at `/portfolio` and a published project at `/p/<slug>`, with nothing private.

## Acceptance criteria
- [ ] `/portfolio` lists PUBLIC projects (allowlisted fields, links to `/p/<slug>`, a calm empty state); `/p/[slug]` renders one PUBLIC or UNLISTED project; private and unknown slugs share the same 404; `generateMetadata` uses the same query and only the name and summary.
- [ ] Routes are dynamic and uncached, keep the ADR-014 headers, nonce CSP and `noindex`; the middleware leaves them public; the home page links to the portfolio.
- [ ] Tests for the pages and the middleware; `privacy-auditor` (stronger model, pre-public) and `reviewer` pass; `pnpm lint`, `pnpm typecheck` and `pnpm test` pass (exit codes in handoff).

## Files in scope
- `src/app/portfolio/page.tsx`, `src/app/p/[slug]/page.tsx`
- `src/modules/portfolio/components/**`
- `src/app/page.tsx`, `src/middleware.ts`
- `tests/portfolio-pages.test.tsx`, `tests/middleware.test.ts`
- `scripts/smoke-lib.ts` (public pages are not redirected)

## Context (read only these)
- ADR-014, ADR-018, `src/middleware.ts`

## Out of scope
- Indexing, sitemaps, custom domains (open questions).
