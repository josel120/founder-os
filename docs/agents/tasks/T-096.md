# T-096: Spanish for Home, Ideas, Problems and Decisions

- Status: todo
- Owner: claude
- Size: M
- Depends on: T-095

## Goal
Every interface string on Home, Ideas, Problems and Decisions renders in Spanish when the owner picks ES, and stays English otherwise.

## Acceptance criteria
- [ ] Every user-visible literal in the files in scope goes through `t()` (server: `const t = await getT()` from `@/lib/i18n/server`; client: `const t = useT()` from `@/lib/i18n/client`), including labels, placeholders, buttons, aria-labels, status and error messages, empty states, enum labels and page metadata titles (`generateMetadata`).
- [ ] Server action and Zod messages stay English in code; the component that shows them wraps them: `t(result.error)`. Messages with numbers get a `{name}` pattern key.
- [ ] Spanish entries only in `src/lib/i18n/es/cockpit.ts`, `ideas.ts`, `problems.ts`, `decisions.ts` (neutral Latin American Spanish, tuteo, same tone as `common.ts`). Keys already in `common.ts` are reused, not duplicated with another translation.
- [ ] English output unchanged: existing unit tests still pass unmodified, except where a test renders a component that now needs no change.
- [ ] `pnpm typecheck`, eslint on changed files and `pnpm test` pass (exit codes in handoff).

## Files in scope
- `src/modules/cockpit/**`, `src/modules/ideas/**`, `src/modules/problems/**`, `src/modules/decisions/**`
- `src/app/private/page.tsx`, `src/app/private/ideas/**`, `src/app/private/problems/**`, `src/app/private/decisions/**`
- `src/lib/i18n/es/cockpit.ts`, `ideas.ts`, `problems.ts`, `decisions.ts`

## Context (read only these)
- `docs/DECISIONS.md#adr-023`, `src/lib/i18n/**`, `src/components/workspace-nav.tsx` (example)

## Out of scope
- Owner records (never translated), other areas' catalogs, `src/lib/i18n` core files.
