# T-006: Authenticated E2E with a disposable database

- Status: doing
- Owner: claude
- Size: M
- Depends on: T-002

## Goal
The current E2E covers only anonymous and auth UI. Add signed-in coverage (capture idea, change status, cross-owner denial) against a throwaway PostgreSQL, never the owner's database.

## Acceptance criteria
- [ ] The E2E setup refuses to run unless `DATABASE_URL` points at a database clearly marked disposable (for example, its name ends in `_e2e`).
- [ ] Owner account created through the `OWNER_SETUP_TOKEN` flow (ADR-005) inside the test setup only.
- [ ] Tests: capture → list; status change persists; a second account is denied.
- [ ] CI job provisions a Postgres service for it. Local runs are documented in CONTEXT.md.
- [ ] `pnpm typecheck`, lint on changed files and unit tests pass (exit codes in handoff)
