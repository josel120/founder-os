# T-080: Import preview, confirm and undo actions

- Status: todo
- Owner: claude
- Size: M
- Depends on: T-079

## Goal
The owner previews an import, confirms it in one transaction, and can undo a whole import.

## Acceptance criteria
- [ ] `previewFinanceImport` (owner-scoped, size-checked, returns headers, sample rows, per-row errors, and which rows already exist by `import_key`); `confirmFinanceImport` inserts the batch and new rows in one transaction with `ON CONFLICT DO NOTHING` on the key, returns counts; `undoFinanceImport(importId)` deletes that import's transactions and the batch, owner-scoped; `listFinanceImports`.
- [ ] Tests incl. cross-owner and anonymous refusal, idempotent re-import; `reviewer` + `privacy-auditor`; `pnpm lint`, `pnpm typecheck`, `pnpm test` pass.
