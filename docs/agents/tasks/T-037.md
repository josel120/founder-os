# T-037: Verify Research workflows and privacy end to end

- Status: todo
- Owner: claude
- Size: M
- Depends on: T-036

## Goal
Prove in CI that evidence works for the owner and cannot leak or be changed across owners or anonymously.

## Acceptance criteria
- [ ] Signed-in E2E: capture evidence on an idea and on a problem, edit it, filter by signal, and see it on the idea page.
- [ ] Owner A cannot read or edit owner B's evidence, or attach evidence to B's idea/problem. B's rows are seeded only in the guarded `_e2e` DB, and the tests assert that rows are unchanged.
- [ ] Anonymous evidence mutations are rejected and rows are unchanged.
- [ ] A `javascript:` source URL is rejected. Stored links carry a safe `rel`.
- [ ] CI run ID and E2E counts recorded in the handoff.
