## Goal
Let the owner create, list, read and edit private Projects with validated lifecycle and operational status fields.

## Acceptance criteria
- [ ] Add Zod schemas for create and content/status updates, including safe slug and URL validation where used.
- [ ] Add owner-scoped queries and explicit-result actions using session owner ID plus ID + owner_id + PRIVATE predicates.
- [ ] Preserve separate lifecycle and operational status fields; validate waiting fields consistently.
- [ ] Add tests for anonymous, cross-owner, invalid input, missing rows, database errors and success.
- [ ] Keep private project data out of public routes and logs.
