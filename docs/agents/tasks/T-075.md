# T-075: GitHub client and sync service

- Status: todo
- Owner: claude
- Size: M
- Depends on: T-073

## Goal
Server code turns a project's GitHub URL into a stored snapshot, safely and without leaking anything.

## Acceptance criteria
- [ ] `parseGitHubRepository(url)` accepts only `https://github.com/<owner>/<repo>` (optional `.git`, trailing slash) with GitHub's name rules.
- [ ] `src/modules/github` client: fetch with timeout to `GITHUB_API_URL` (default `https://api.github.com`, overridable for tests only outside production), `Authorization: Bearer GITHUB_TOKEN`, API version header; reads repo, open PR count (search API or pulls `per_page=1` + Link header), latest release (404 = none); maps 401/403/404/429/5xx to ADR-019 codes; never logs bodies or the token.
- [ ] `syncProjectGitHub(ownerId, projectId)` upserts `project_github` owner-scoped; `syncAllLinkedProjects()` for cron; unlinked or invalid URL removes the snapshot.
- [ ] Unit tests with a stubbed fetch; `reviewer` + `privacy-auditor`; `pnpm lint`, `pnpm typecheck`, `pnpm test` pass.

## Files in scope

- `tests/github-*.test.ts`
