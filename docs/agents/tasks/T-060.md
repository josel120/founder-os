# T-060: Make anonymous E2E wait for the migrated database

- Status: review
- Owner: claude
- Size: S
- Depends on: T-053

## Goal
The anonymous Playwright project has no dependency on `setup`, which migrates the disposable database. Since T-053 every `/api/auth/*` request reads `rate_limit`, so on a fresh CI database an anonymous auth request can race the migration and get a 500. `tests/e2e/auth-ui.spec.ts` checks only headers on `get-session`, so the race hides a real check instead of failing it. Anonymous specs run against a migrated database, and the header check also asserts the status.

## Acceptance criteria
- [ ] The anonymous project cannot hit the server before the database is migrated: for example split migration into its own `migrate` setup project that both projects depend on, keeping TRUNCATE and sign-in in `setup`.
- [ ] The `get-session` security-headers check in `tests/e2e/auth-ui.spec.ts` also asserts a 200 status.
- [ ] No test depends on another's data; the suite stays parallel. Full E2E with the CI env passes twice from a fresh `_e2e` database (drop and recreate it between runs).
- [ ] `pnpm typecheck` and lint on changed files pass (exit codes in handoff)
