## Goal
Server-side create, edit and list of evidence with the ownership rules from ADR-012.

## Acceptance criteria
- [x] Zod schemas: title/summary trimmed and bounded, kind and signal enums, optional `http(s)` source URL only (reject `javascript:`, `data:`, other schemes), exactly one parent ID.
- [x] `createEvidence` gets the owner from `requireAuth()`, verifies the parent Problem or Idea by `id + owner + PRIVATE`, and forces visibility PRIVATE. Kind and signal are always passed explicitly (the columns have no defaults after T-040). Returns explicit results (`ok` / `invalid` / `not_found` / `failed`).
- [x] `updateEvidenceContent` edits content fields only (never the parent, owner or visibility) and checks `UPDATE … RETURNING`.
- [x] Queries: list for owner (optional kind/signal filter), list by owned idea, list by owned problem. All use `owner + PRIVATE`.
- [x] Unit tests cover cross-owner parents, bad URLs and client-supplied owner/visibility being ignored.
- [x] `pnpm typecheck`, lint on changed files and unit tests pass (exit codes in handoff)
