# T-071: Verify the portfolio end to end and audit privacy before going public

- Status: todo
- Owner: claude
- Size: M
- Depends on: T-069, T-070

## Goal
End-to-end proof that only what the owner publishes is public, and that unpublishing is immediate.

## Acceptance criteria
- [ ] Playwright: owner publishes a project as Unlisted then Public, it appears at `/p/<slug>` and then `/portfolio`; the served HTML and RSC payload contain none of the sentinel private values (description, next action, repository, finance, decisions); owner B's published project never shows owner A's data; B cannot publish A's project; unpublish gives a 404 at once; anonymous users cannot call the actions.
- [ ] Pre-public `privacy-auditor` sweep of the whole tree on the stronger model; findings fixed or carded.
- [ ] ROADMAP and PROGRESS updated; `pnpm lint`, `pnpm typecheck` and `pnpm test` pass (exit codes in handoff); E2E green in CI.
