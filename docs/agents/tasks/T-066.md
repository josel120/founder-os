# T-066: Add the project_publication table (migration 0008)

- Status: todo
- Owner: claude
- Size: S
- Depends on: T-065

## Goal
The schema can record which projects are published, how, and with which public summary, without touching the private project row.

## Acceptance criteria
- [ ] `project_publication` per ADR-018: `project_id` PK/FK (cascade), `owner_id` FK (restrict), `visibility` CHECK in (`PUBLIC`,`UNLISTED`), `summary` CHECK 1–500 chars after trim, `published_at`/`updated_at` not null with defaults; index for the public list (`visibility`, `published_at`).
- [ ] Migration 0008 generated with `pnpm db:generate`, additive only; journal updated; older migrations untouched.
- [ ] Schema tests: constraints reject a PRIVATE row, an empty or oversized summary and an unknown project; deleting a project deletes its publication.
- [ ] `schema-reviewer` and `reviewer` pass; `pnpm lint`, `pnpm typecheck` and `pnpm test` pass (exit codes in handoff).
