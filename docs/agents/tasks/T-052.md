# T-052: Fail fast on production env and tune the DB client for serverless

- Status: done
- Owner: claude
- Size: M
- Depends on: T-042

## Goal
Production never runs with auth silently disabled, and database connections suit Vercel + Neon (ADR-016).

## Acceptance criteria
- [x] `env.ts`: enforced on Vercel (`VERCEL=1`, both preview and production) or with opt-in `FOUNDER_OS_STRICT_ENV=1`, skipped during `next build` (`NEXT_PHASE=phase-production-build`) — **not** keyed on `NODE_ENV` (see Handoff: proposed ADR-016 amendment). Missing `DATABASE_URL`, `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL` (https only) or `OWNER_EMAIL` throws one error at startup naming the variable(s), never a value.
- [x] `src/db/index.ts`: `prepare: false` and a small `max` when the URL is a Neon pooled URL (or `DATABASE_POOLED=1`); unchanged otherwise.
- [x] Remove the unused `@neondatabase/serverless` dependency.
- [x] Unit tests for env validation (missing, http URL, valid) and client options.
- [x] `pnpm typecheck`, lint, unit tests and `pnpm build` (without env) pass (exit codes in handoff)
